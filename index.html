ARIN 310 · Introduction to Artificial Intelligence

Interactive Machine Learning Demos

Five hands-on tools for Unit 2. Each one exposes the actual mechanism — the loss being minimized, the search for a better answer, the moments where the algorithm gets it wrong — instead of just showing a black-box result.

Supervised Learning

Every example has a known, correct answer. The model searches for the fit that minimizes error against it.

One Feature

Finding the Line That Fits

Fit a line to real data by hand, then reveal the mathematically optimal one. Introduces loss, error, and the idea of training as a search.

 Multiple Features · 3D

When One Line Isn't Enough

Two features means fitting a plane, not a line. A rotatable 3D scene shows the model's surface directly, with the same reveal-the-best-fit mechanic.

Unsupervised Learning

No labels at all — just structure waiting to be found.

K-Means Clustering

Finding Structure Without Labels

Group unlabeled customers by hand, then watch k-means take over. Includes a real, honest limitation: different starting points can converge to different answers.

Semi-Supervised Learning

A handful of trusted labels, plus a lot of unlabeled data, used together.

Label Propagation · Real Kaggle Data

Real Tweets, Real Ambiguity

Built on real tweets from Kaggle's "NLP with Disaster Tweets" competition. Four hand-labeled seeds spread labels outward — including, honestly, to tweets that only sound like disasters.

Deep Learning

Why one line, one neuron, or one layer isn't always enough.

Neurons · Decision Boundaries

Build a Brain: One Neuron, Two, or Three

Build the classifier one neuron at a time. Adjust each neuron's boundary and see how combining simple linear decisions creates more complex decision regions.

 Neural Network · Live Backpropagation

Why Deep Learning Needs More Than One Line

A real neural network trained in the browser on a quality-control dataset no straight line can separate. Watch the architecture diagram's actual weights change as training runs, and see why a few deliberately mislabeled points keep accuracy honest.
